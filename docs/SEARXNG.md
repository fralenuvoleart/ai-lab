# SearXNG — Self-Hosted Metasearch Engine

> Docker: `searxng` + `searxng-redis` | Port: `8888` (localhost only) | RAM: ~112MB

## URL

- API: `http://127.0.0.1:8888/search?q=query&format=json`
- Config: `http://127.0.0.1:8888/config`
- Container: `/opt/searxng/docker-compose.yml`
